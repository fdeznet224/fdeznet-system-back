Guía 01 de 08

Configura la red e importa tus clientes

Prepara FdezPay desde el primer acceso: conecta el MikroTik, registra planes y redes, define la cobranza, organiza zonas y carga los clientes existentes.

Antes de comenzar

Orden recomendado

Completa los catálogos antes de importar. Así cada cliente podrá quedar asociado al router, plan, red, ciclo de cobro y zona correctos desde el primer momento.

  1. 1
    VPN, si se necesitaConectividad privada hacia el MikroTik y sus redes internas.
  2. 2
    Nodo MikroTikVinculación mediante RouterOS REST.
  3. 3
    Planes de InternetPrecios y velocidades comerciales.
  4. 4
    Redes IPSegmentos y gateways administrados por IPAM.
  5. 5
    Ciclos de cobroGeneración, pago, gracia, corte y reconexión.
  6. 6

  7. 7

La VPN es opcional. Si la VPS ya puede alcanzar una IP pública o dominio del MikroTik, vincula el nodo directamente y continúa con los planes.

Preparación

Requisitos previos

  • FdezPay instalado y una cuenta con permisos administrativos.
  • MikroTik con RouterOS v7 o superior.
  • Usuario dedicado del router con permisos suficientes para REST.
  • Conectividad mediante WireGuard o una dirección pública accesible.
  • Método de gestión definido: PPPoE o IP estática.
Seguridad: evita usar la cuenta administrativa principal. Crea una cuenta dedicada, limita su origen y nunca publiques contraseñas, llaves privadas ni tokens.

Punto de partida

Abre las herramientas administrativas

Desde el Dashboard despliega Configuración. En la pantalla General encontrarás Túneles VPN, Plantillas de Facturación, Gestión de Zonas e Importar Clientes.

Paso 1

Crea un túnel VPN hacia el MikroTik

Utiliza WireGuard cuando el router no tenga una dirección pública alcanzable desde la VPS. En Configuración → Túneles VPN, pulsa Nuevo túnel y selecciona Nodo / Router.

Datos del acceso

CampoQué debes indicar
TipoNodo / Router para conectar un MikroTik.
IdentificadorUn nombre reconocible, por ejemplo Torre Principal o Router Zona Norte.
Subredes detrás del MikroTikRedes internas que también deberán alcanzarse: ONUs, antenas, APs u otros equipos.
Formato correcto: usa redes como 192.168.2.0/24, no una dirección de equipo como 192.168.2.1/24. Puedes separar varias redes con coma o salto de línea; FdezPay las normaliza al crear el túnel.

Genera las llaves y aplica el script

  1. Pulsa Generar llaves.
  2. En la tarjeta creada, abre Script MikroTik y pulsa Copiar.
  3. Abre una terminal del router mediante WinBox, WebFig o SSH.
  4. Pega y ejecuta el script completo.
  5. Conserva la IP privada asignada; la usarás al vincular el nodo.

Paso 2

Vincula el MikroTik como nodo

Abre Infraestructura → Nodos / Routers y pulsa Vincular Nodo.

CampoUso
NombreIdentificador interno del router.
Dirección IPIP privada asignada por la VPN o IP/dominio público accesible.
Usuario y contraseñaCredenciales dedicadas para la integración REST.
PuertoPuerto WWW/HTTP de RouterOS REST; normalmente 80.
ModoPPPoE para PPP Secrets o IP estática según el diseño de red.
No uses 8728 por costumbre. Ese puerto corresponde al API tradicional. La integración de FdezPay con RouterOS v7 usa REST sobre el servicio WWW/HTTP, normalmente puerto 80 o el puerto personalizado de ese servicio.

Después de vincularlo, utiliza Ping en la tarjeta. Si no responde, revisa IP, puerto WWW, credenciales, VPN y firewall antes de continuar.

Paso 3

Crea los planes de Internet

En Infraestructura → Planes de Internet, pulsa Nuevo Plan. Crea todos los planes comerciales que utilizarás antes de descargar el Excel de importación.

Indica nombre comercial, precio, router destino, bajada y subida. Las ráfagas son opcionales; si no las utilizas, conserva sus valores en cero.

Paso 4

Registra las redes IP de clientes

IPAM permite controlar qué segmentos pertenecen a cada router y reduce el riesgo de reutilizar una dirección ya ocupada. Abre Infraestructura → Redes IP (Pools) y pulsa Nueva Red.

Selecciona el router, escribe un nombre, el segmento CIDR y su gateway. Para una red /24 con gateway 192.168.2.1, el segmento normalmente será 192.168.2.0/24.

Paso 5

Configura los ciclos de cobro

En Configuración → Plantillas de Facturación, crea una política por cada calendario utilizado. Por ejemplo, puedes tener clientes con pago el día 1 y otros con pago el día 15.

CampoSignificado
AnticipaciónDías antes del pago en los que se genera la factura.
Día de pagoFecha principal de vencimiento mensual.
GraciaDías posteriores al pago antes del corte.
IVAPorcentaje aplicable; utiliza 0 cuando no corresponda.
ReconexiónCargo después de reactivar; utiliza 0 si no se cobra.
WhatsAppActiva los avisos automáticos del ciclo.

Paso 6

Crea las zonas geográficas

Las zonas organizan clientes por colonia, barrio, comunidad o sector. Un mismo MikroTik puede atender varias; durante la preparación del Excel podrás asignar la zona correcta a cada cliente.

  1. Escribe el nombre de la zona.
  2. Pulsa Crear Zona.
  3. Repite el proceso hasta completar tu cobertura.

Paso 7

Importa los clientes desde MikroTik

Con los catálogos listos, abre Configuración → Importar Datos. Realiza un lote por MikroTik para que la revisión y la corrección de errores sean manejables.

Configura y descarga el lote

Selecciona router, red IP, zona, plantilla de facturación y plan. Estos valores sirven como base; si el router contiene clientes distintos, podrás corregir cada fila en el Excel.

Revisa el archivo Excel

Guarda la plantilla y revisa cada cliente. Corrige plan, zona, ciclo de cobro y red cuando el valor inicial no corresponda.

Los catálogos empiezan en 0. En las columnas de plan, zona y plantilla: el primer elemento es 0, el segundo 1, el tercero 2 y así sucesivamente.

Sube e inicia la importación

  1. Selecciona o arrastra el Excel corregido.
  2. Comprueba que aparezca el nombre del archivo.
  3. Pulsa Iniciar Importación.
  4. Revisa clientes creados, registros con error y estado final.
  5. Corrige los errores antes de continuar con el siguiente router.

Finalización

Comprueba la configuración

  • La VPN se creó sólo cuando fue necesaria y el peer tiene handshake.
  • El nodo responde a Ping y usa RouterOS REST por el puerto WWW correcto.
  • Todos los planes comerciales están asociados al router correspondiente.
  • Los segmentos y gateways están registrados en IPAM.
  • Las fechas de generación, pago, gracia y corte son correctas.
  • Las zonas necesarias existen antes de importar.
  • El Excel fue revisado fila por fila y conserva el formato .xlsx.
  • Los registros rechazados se corrigieron antes de cerrar el lote.
Flujo completo: VPN, si aplica → Nodo MikroTik → Planes → Redes IP → Ciclos de cobro → Zonas → Descargar y corregir Excel → Importar clientes.
