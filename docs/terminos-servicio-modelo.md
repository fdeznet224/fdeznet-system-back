# Términos de licencia y servicio — modelo

Plantilla sujeta a revisión legal y a completar con los datos comerciales de
FdezNet y del cliente.

## Licencia

FdezNet concede al cliente, durante la vigencia del plan contratado, una
licencia limitada, no exclusiva, no transferible y para una sola instalación
autorizada. El cliente no puede redistribuir, revender, descompilar ni entregar
acceso al código fuente salvo autorización escrita.

## Plan, pago y suspensión

El contrato debe indicar precio, moneda, impuestos, fecha de corte, periodo de
gracia, límites de abonados y routers, modalidad demo y consecuencias de falta
de pago. La suspensión de la licencia no elimina los datos del cliente.

## Operación y soporte

Se deben definir horario y canal de soporte, tiempo objetivo de respuesta,
mantenimiento programado, alcance de configuración de MikroTik/OLT, respaldo,
recuperación y responsabilidades sobre conectividad, VPS y equipos del cliente.

## Integraciones de terceros

WhatsApp Web, Gmail, bancos, MikroTik, fabricantes de OLT, VPS y otros servicios
son operados por terceros. Su disponibilidad y reglas pueden cambiar. El motor
basado en WhatsApp Web debe describirse como integración opcional sin garantía
de continuidad; para operación empresarial regulada debe ofrecerse la API
oficial cuando corresponda.

## Datos y terminación

El cliente es responsable de contar con avisos y autorizaciones para los datos
de sus abonados. Al terminar el servicio se definirá un plazo para exportar la
información, entregar el respaldo acordado y eliminar copias restantes, salvo
retención legal.

## Responsabilidad

El contrato definitivo debe establecer garantías, exclusiones, límite de
responsabilidad, propiedad intelectual, confidencialidad, jurisdicción,
impuestos y mecanismo de controversias.
